DINDU GTA V — REAL 3D TEST CELL

This folder is a separate prototype. The main game index.html is not changed.

It loads a real rigged human GLB and a detailed blue sedan GLB through Three.js.
The human model is a high-detail adult male base model with the original T-shirt/shorts outfit and baked Walk/Run clips. It is not yet the requested custom black hoodie outfit.

After this folder is pushed to GitHub Pages, open:
https://chijinduu956-dotcom.github.io/dindu-gta-v-game/real-3d-test/

Controls:
- Drag the 3D scene to orbit the camera.
- Use the left virtual joystick on a phone, or WASD / arrow keys on desktop, to move.
- WALK and RUN switch the imported animation clips.
- RESET VIEW recentres the camera.

If the models fail to load, check the browser connection and confirm both GLB files are present in assets/.
